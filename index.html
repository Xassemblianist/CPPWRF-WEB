    How the check works

    For each of the file's variables and each of its output times, the page takes the SHA-256 of the values as stored in the NetCDF file and compares it with expected/<case>.json. That file was written once from the native build: . The whole file is compared as well; the wasm build writes it with the same CPPWRF writer and the same NetCDF-C version.

    Bit identity in the browser rests on three things: no fused multiply-add contraction and no fast-math in the wasm, CPPWRF's own port of glibc's libm and libmvec instead of Emscripten's math library, and the same order of operations as WRF, statement by statement.
